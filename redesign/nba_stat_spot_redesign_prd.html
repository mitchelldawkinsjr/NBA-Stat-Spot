NBA Stat Spot — UI/UX Redesign Brief Project Overview NBA Stat Spot is a web application for NBA sports bettors and analysts. It surfaces actionable betting intelligence (player prop recommendations, game predictions, over/under analysis, parlay construction, and bet tracking) using ML models and LLM reasoning. Visual Style & Tone: - Modern, high-density, sports-data-forward (The Athletic + Action Network + Bloomberg terminal). - Dark-mode first. - Precision, confidence, trust. Target User: - Recreational-to-semi-serious NBA bettors. - Needs quick scans and deep drills. - Desktop-primary but responsive-required. Navigation & Layout: - Global layout with persistent header (Logo, Season selector, Dark/Light toggle). - Nav items: Dashboard, Explore, Over/Under, Parlay Builder, Bet Tracker, Accuracy. - De-emphasized Admin link. Page Inventory: 1. Dashboard: Today's Games Strip, Top Picks, AI Pick of the Day, Best Match, Stat Leaders, Quick Prop Lab, Daily Props Panel, News Feed. 2. Explore: Player Search, Team Browse, Prop Evaluation Panel. 3. Player Profile: Header, Live Stats, Game Log, Trend Charts, Prop Distribution, Matchup, Streaks. 4. Team Profile: Header, Roster, Team Ranks, Efficiency Charts. 5. Over/Under: Live Games Feed, Per-Game Analysis, Analyze-All AI. 6. Game Prediction: Matchup, Winner Prediction, Comparison Metrics, Key Players, H2H. 7. Parlay Builder: Search & Add legs, Summary Panel (Combined confidence), Review/Save. 8. Bet Tracker: Financial Summary, Bets/Parlays List, Add Forms, Quick Prop Suggestion. 9. Accuracy: Transparency tabs (Matchups, AI Pick, Top Picks, Combined). 10. Admin Dashboard: System health, Sync status, Action buttons. Design Language: - Color: Green (#10B981) for Over/Win/LOCK; Red (#EF4444) for Under/Loss; Blue (#17408B) for Primary/Predictions; Amber for LEAN; Purple for AI content. - Typography: Outfit (Sans-serif). - Key Components: Tier badges, Confidence bars, Probability rings, Game/Prop cards, Skeleton loaders.
